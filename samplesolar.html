☀️ Karnataka Solar Prediction

This data-driven platform maps real-time solar harvesting capacities across Karnataka. It dynamically pairs live local weather metrics from the Open-Meteo API with an analytical model to calculate expected solar yields.

⚙️ Understanding the Analytics & UI

🗺️ Regional Map Boundaries

Interactive district segments adapt color states immediately upon selection to pull matching localized coordinate arrays.

🌡️ Temperature & Humidity Constraints

Photovoltaic setups function optimally under cool ambient light. Spikes in heat degrade active element response, while high moisture scattering patterns dull aggregate solar intensity.

☁️ Cloud Cover Impacts

The volumetric density of clouds restricts direct radiation paths, filtering illumination down to scattered, multi-directional ambient rays.

⚡ Radiation (W/m²) & Solar Hours

Direct normal and diffuse horizontal measurements index the true current physical power payload meeting flat target systems over clear trackable hours.

🤖 Model Yield Output (kWh/m²/day)

The primary pipeline result. Calculates exactly how many kilowatt-hours of electrical energy a standard square meter array will return across daily cycles given current parameters.
